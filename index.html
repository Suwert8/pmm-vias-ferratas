Conexión con GitHub

Puedes ver las ferratas sin token. Para guardar, editar o eliminar necesitas un token de GitHub:

  1. En GitHub ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Pulsa Generate new token y en Repository access elige solo pmm-vias-ferratas.
  3. En Permissions → Contents selecciona Read and write.
  4. Copia el token y pégalo aquí.
